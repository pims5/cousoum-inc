# COUSOUM · CYBER — pack d'intégration public

## À intégrer
- Copier `assets/css/cyber.css` et `assets/js/cyber.js`.
- Insérer le fragment FR dans `/fr/index.html` et le fragment EN dans `/en/index.html`.
- Charger `cyber.css` après le CSS principal et `cyber.js` avec `defer`.
- Ajouter le lien de navigation `#cyber` dans les deux langues.

## Ne pas publier
Le diagnostic critique intégral, les hypothèses juridiques non confirmées, les faiblesses internes, les modèles de contrats, les données clients, les preuves, les configurations, les scans, la Timeline et les archives Takeout restent hors du dépôt public.

## Positionnement public autorisé
Diagnostic essentiel, gouvernance & accès, continuité & accompagnement, limites publiques, méthode AMANAH présentée comme méthode interne.

## Gate
Ne pas activer de pentest, SOC, certification, réponse forensique ou activité potentiellement réglementée avant clarification juridique, compétence démontrée, assurance et contrat validé.
