# COUSOUM · INC — Pack site de base

## Contenu
- `index.html` : page d’accueil
- `style.css` : styles adaptatifs mobile / tablette / ordinateur
- `site.js` : menu mobile et année du pied de page
- `site.webmanifest` : configuration PWA
- `sitemap.xml` et `robots.txt` : référencement
- `404.html` : page d’erreur

## Important avant publication
Ce pack est une base de site conçue à partir du contexte du projet ; ce n’est pas une copie complète du dépôt actuel et il ne contient pas les images ni les logos d’origine. Pour préserver l’identité visuelle, récupérez les vrais fichiers présents dans le dépôt et ajustez les chemins :
- `hero-dakar.webp`
- `favicon.ico`
- `apple-touch-icon.png`

Sans `hero-dakar.webp`, la page reste lisible mais l’image de fond ne s’affichera pas. L’adresse `contact@cousoum.com` est indicative : remplacez-la par l’adresse officielle confirmée avant publication.

## Publication GitHub Pages
1. Ouvrir le dépôt `pims5/cousoum-inc`.
2. Télécharger une sauvegarde complète du dépôt actuel avant toute modification.
3. Comparer ces fichiers avec la version publiée avant de remplacer quoi que ce soit.
4. Ajouter les images et logos réels, puis corriger l’adresse de contact.
5. Importer les fichiers dans le dépôt, committer les changements et attendre le déploiement GitHub Pages.
6. Tester le site sur iPhone/iPad et ordinateur.

## Sécurité
GitHub Pages sert des pages publiques. Ne placez pas de documents privés, clés API secrètes, mots de passe ou données clients dans ce dépôt. `robots.txt` ne protège pas les contenus. Une zone privée nécessite une authentification et des règles serveur adaptées.
